По заданиям было создано 5 Python-файлов, каждый отвечает за одно задание:

(Среднее 1, задание 6) progressbar.py: Прогрессбар. По кнопке «Запустить» индикатор постепенно заполняется от 0 до 100%. После завершения его можно запустить снова. Для обновления используется метод after(), поэтому окно остаётся отзывчивым.

(Среднее 2, задание 8) filedialog.py: Диалог выбора файла. Кнопка открывает стандартное окно выбора файла, после выбора в приложении отображается путь. При отмене предыдущий результат сохраняется.

(Среднее 3, задание 2) textinput.py: Окно с текстовым полем и кнопкой. Введённый текст выводится в окне при нажатии кнопки или клавиши Enter.

(Повышенное 1, задание 4) graph.py: График matplotlib внутри Tkinter. График встраивается в окно с помощью FigureCanvasTkAgg. В выпадающем списке можно переключиться между функциями sin(x) и cos(x).

(Повышенное 2, задание 10) chat.py: Локальный чат. Приложение использует TCP-сокеты и Tkinter. Сервер работает на адресе 127.0.0.1 и порту 50505 и пересылает сообщения всем подключённым окнам, в том числе отправителю. Для приёма сообщений используются отдельные потоки, а интерфейс обновляется через очередь в главном потоке.


Нужен Python 3.9 или новее с Tkinter и рабочим графическим окружением. В Windows и macOS Tkinter обычно входит в установку Python.

Для графика установите matplotlib из папки проекта:

python -m pip install -r requirements.txt

Остальные задания используют стандартную библиотеку Python.

Для проверки чата запустите `chat.py` в двух отдельных терминалах на одном компьютере. В первом окне введите имя и нажмите «Создать сервер» (это окно также подключится к чату). Во втором окне введите другое имя и нажмите «Подключиться». Отправьте сообщения из обоих окон: они появятся у обоих участников. Можно подключить дополнительные окна. Закрытие окна с сервером отключает всех участников; для повторного подключения перезапустите окна. Если порт 50505 занят, закройте другую копию сервера и повторите запуск. Сообщения не сохраняются и доступны только на этом компьютере.
